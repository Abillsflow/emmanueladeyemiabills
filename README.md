# Emmanuel Adeyemi (Abills) — Portfolio

A custom-coded personal portfolio showcasing digital design, Webflow development, and e-commerce work.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Lucide icons
- Vercel deployments connected to GitHub

## Local development

Install a current Node.js LTS release, then run:

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before launch

- Replace project concept visuals with approved project screenshots.
- Verify the preferred contact email and social profile links.
- Add a real portrait and social share image if desired.
- Test navigation, contact links, accessibility, and mobile layouts.
- Connect a custom domain when ready.

## Deployment

The `main` branch is connected to Vercel. Commits to the production branch trigger deployment automatically.
